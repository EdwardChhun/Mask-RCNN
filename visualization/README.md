## Visualization

Some scripts to visualize data from the default metrics.json output.

### Setup

1. Run `python -m venv .venv` to create a virtual environment.
2. Activate the virtual environment:
    - Windows
      - `source .venv/bin/activate.bat` (cmd) `source .venv/bin/activate.ps1` (Powershell)
    - Linux / MacOS
      - `source .venv/bin/activate`
3. Run `pip install -r requirements.txt` to install the required packages.

### Usage

1. Run `python main.py` and follow the instructions.

   **OR**

2. Import `visualize` and use the functions in your own script.
